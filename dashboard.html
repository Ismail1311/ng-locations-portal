Quick Start Guide

Follow these steps to make your first API request.

1

Generate an API Key

Create a secure key in the API Keys section to authenticate your requests.

Go to API Keys
2

Make a Request

Use the key in the header of your HTTP requests to fetch Nigerian locations.

fetch.js
const API_KEY = 'YOUR_API_KEY';
const BASE_URL = 'https://ng-locations-api.onrender.com/api/v1';

fetch(`${BASE_URL}/states`, {
  method: 'GET',
  headers: {
    'x-api-key': API_KEY
  }
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error(error));
