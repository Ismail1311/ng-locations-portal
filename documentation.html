API Reference

Welcome to the NG Locations API. This RESTful API provides instant access to accurate data for all 36 Nigerian states, the FCT, and their respective Local Government Areas (LGAs).

Base URL

https://ng-locations-api.onrender.com/api/v1

All API endpoints are relative to this base URL.

Authentication

All API requests must be authenticated using your API key. You must include your key in the x-api-key header of every request.

⚠️ Security Warning: Never expose your API key in client-side code (like browser JavaScript or mobile apps). Always make requests from your secure backend server.

Quick Start (JavaScript)

Copy this code and replace YOUR_API_KEY with the key from your dashboard.

JavaScript (Fetch)
const API_KEY = 'YOUR_API_KEY';
const BASE_URL = 'https://ng-locations-api.onrender.com/api/v1';

fetch(`${BASE_URL}/states`, {
  method: 'GET',
  headers: {
    'x-api-key': API_KEY
  }
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error(error));

Get All States

GET /states

Returns a list of all 36 Nigerian states and the Federal Capital Territory (FCT). This endpoint is useful for populating dropdown menus on your frontend.

Response Object

JSON
{
  "success": true,
  "count": 37,
  "data": [
    { "state": "Abia", "alias": "abia" },
    { "state": "Adamawa", "alias": "adamawa" },
    // ... all other states
  ]
}

Get LGAs by State

GET /states/:alias/lgas

Returns a list of all Local Government Areas for a specific state. Replace :alias with the lowercase state alias (e.g., lagos, kano, akwa_ibom).

Path Parameters

Parameter Type Description
alias string The lowercase alias of the state (e.g., "lagos").

Example Request

cURL
curl -X GET "https://ng-locations-api.onrender.com/api/v1/states/lagos/lgas" \
  -H "x-api-key: YOUR_API_KEY"

Response Object

JSON
{
  "success": true,
  "state": "Lagos",
  "count": 20,
  "lgas": [
    "Agege",
    "Ajeromi-Ifelodun",
    "Alimosho",
    // ... all other LGAs
  ]
}

Error Codes

The API uses standard HTTP response codes to indicate the success or failure of an API request.

Code Meaning Description
200 OK Everything worked as expected.
401 Unauthorized No API key provided, or the key is invalid.
403 Forbidden The API key has been revoked by the owner.
404 Not Found The requested state alias does not exist.
429 Too Many Requests You have exceeded your plan's rate limit.
