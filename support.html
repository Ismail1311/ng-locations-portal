How can we help?

Frequently asked questions about the NG Locations API.

How do I authenticate my API requests? ▼
You must include your API key in the header of every request. The header key is x-api-key and the value is your generated key.
What happens if my API key is leaked? ▼
Immediately log into your Dashboard, go to the API Keys tab, and click "Revoke" next to the compromised key. Then, generate a new one. Revocation happens instantly.
Are there rate limits on the Free plan? ▼
Yes. The Free plan allows up to 1,000 requests per month. You can upgrade to the Premium plan from your Profile page for higher limits.
